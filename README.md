# Wizard-Chess

Wizaard Chess is an open source project that aims to have a physical chessboard that can record the pieces, positions, and movements of a chess game. This project combines the experience of playing on a physical chessboard with the advantages of a digital chess game!

Using shift registers, hall effect sensors, and magnets Wizard Chess senses where pieces are on the squares and records that information. Using other open source chess libraries the board is able to detect and record moves. When an illegal move is made the board alerts the player on the display screens. Display screens also display a clock that players can adjust the time limit of as well as stop and start with buttons on their side of the board. 

# Repository Navigation
First navigate to the project materials section. This will show the bill of materials for the project. Listed in it is all if the parts that were used in the project, as well as the amount needed for each part, the cost, and link to purchase the part for yourself! From there navigate to the chessboard CAD. The link in the document will take you to an onshape file that can be copied. This file contains the full CAD for the project! Next, find the Chess Board KiCAD. This is the schematic for the board and will tell you how the electronics are supposed to be connected. Once you are ready for testing, there are files for tetsting the shift registers on their own, testing the shift registers with the hall effect sensors, and testing the chess library.
